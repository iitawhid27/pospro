ব্যাকআপ

সব ডেটা (প্রোডাক্ট, কাস্টমার, ব্যবহার, সাপ্লাই, বিন) একটি ফাইলে সেভ করে রাখুন। ফোন বা ব্রাউজার বদলালে রিস্টোর করে ফেরত পাবেন।

অটো ব্যাকআপ (Gmail)

অ্যাপ খুললে (দিনে একবার) এবং ডেটা বদলালে নিজে নিজেই ব্যাকআপ ফাইল আপনার Gmail-এ চলে যাবে।

⚙ প্রথমবার সেটআপ (২ মিনিট)
  1. script.google.com এ যান (যে Gmail-এ ব্যাকআপ চান সেটা দিয়ে লগইন) → New project
  2. নিচের কোড কপি করে সব কোড মুছে পেস্ট করুন → Save
  3. Deploy → New deployment → Web app। Execute as: Me, Who has access: Anyone → Deploy → অনুমতি (Authorize) দিন
  4. যে Web app URL পাবেন সেটা উপরের ঘরে বসান, চালু করুন, তারপর “এখনই পাঠান” চাপুন
